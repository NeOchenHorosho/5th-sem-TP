Карта экранов прототипа

Ссылки ниже показывают связи между экранами и работают как обычные переходы.

  • Главная → Авторизация — кнопка «Войти» в шапке.
  • Главная → Оформление отправления — кнопка «Оформить отправление».
  • Оформление → Список отправлений — после сохранения заявки.
  • Список → Карточка отправления — ссылка «Открыть» в строке.
  • Карточка → Редактирование / Удаление.
  • Пользователи → Подтверждение удаления — общий экран для заказов и пользователей.
  • Любой экран → Ошибка — при сбое загрузки данных.
